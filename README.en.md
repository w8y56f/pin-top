# PinTop

[简体中文](README.md)

PinTop is a gallery utility for Android 11 and later. It updates the last-modified time of local files so older screenshots, photos, animated images, and videos appear at the top of galleries sorted by modification time, newest first. File contents, photo EXIF data, and embedded video metadata stay intact.

## Usage

Select one or more items in your gallery, tap **Share**, and choose **PinTop**. If Android asks for permission to modify the files, tap **Allow**. When you share several items, PinTop preserves their relative order by their original modification times.

If your gallery sorts by capture date, switch to modification time to see the updated order. Some Android 11 devices restrict changes to files created by other apps.
